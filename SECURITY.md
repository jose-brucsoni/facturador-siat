# Seguridad

## Secretos

- Nunca commits tokens del SIAT, certificados, contraseñas ni `.env` con valores reales.
- Usa `.env.example` como plantilla; los secretos viven solo en el entorno local o en un gestor de secretos.
- No abras issues ni PRs pegando NIT reales, XML de contribuyentes o capturas con datos fiscales.

## Reportes

Si encuentras un problema de seguridad en este proyecto de demostración, descríbelo sin incluir credenciales ni datos personales.
